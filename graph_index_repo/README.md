# Graph Index Repository

This directory stores pre-built graph index files generated by the Artea framework.

## File Format

Graph index files use the `.index` extension and contain serialized search graph structures in binary format.

## Usage

Index files are generated using the `build_conv_graph` tool:

```bash
./build/examples/build_conv_graph \
    --dataset sift-1m \
    --output graph_index_repo \
    --extracted-nbr-size 64
```

The generated index files can be loaded directly for search operations without rebuilding the graph.

## Note

`.index` files are excluded from version control via `.gitignore` due to their large size.
